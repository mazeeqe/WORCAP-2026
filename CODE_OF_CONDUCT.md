# Código de Conduta

Este projeto adota um ambiente colaborativo, respeitoso e livre de assédio. Comentários devem tratar do trabalho, não da pessoa. Discriminação, intimidação, exposição de dados pessoais e conteúdo ofensivo não são aceitos.

Ocorrências podem ser comunicadas de forma privada por **Security > Report a vulnerability**. Os mantenedores podem remover conteúdo inadequado e restringir participantes que coloquem a comunidade em risco.
